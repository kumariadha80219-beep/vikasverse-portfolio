# VIKASVERSE — Personal Portfolio

A futuristic, responsive portfolio for Vikas Kumar, with a profile photo and an interactive Superpower Lab.

## Files
- `index.html` — complete website (HTML, CSS and JavaScript).
- `vikas-profile.jpeg` — profile photo used on the home page.

## Run locally
Keep both files in the same folder and open `index.html` in a browser.

## Interactive feature
Open **Superpower Lab** and try: `HELP`, `ENGINEER`, `BUILDER`, `CREATOR`, `LEADER`, `FUTURE`, or `CLEAR`.

- Review all profile details and achievements; remove or correct anything that is inaccurate.

## Deploy with AWS Amplify Hosting
1. Push both files to a GitHub repository.
2. In AWS Console, open AWS Amplify and choose **Host web app**.
3. Connect GitHub and select your repository and `main` branch.
4. For this plain static site, publish the repository root; no build command is needed.
5. Deploy and test the generated URL on desktop and mobile.
